# Keys: which ones, where they go

Ask only for the keys the approved plan's channels need. Sign-up links, free tiers and prices: **`kb/tools.md`**
(the only place for links; show the plain URL when a link still reads `{{REF:…}}`). Step-by-step clicks:
`guides/`. Never print a key, never write one to `kb/` or git.

Where each key goes:
- **Mode A:** `.env.local` + Vercel env (`create_project_env` with the connector, or `vercel env add <NAME> production`), then redeploy.
- **Mode B:** `.env.local` + the host's env vars, then rebuild.
- **Mode C:** `.env.local` (local session). In a cloud session or scheduled task: the cloud environment's secrets
  (`guides/claude-cloud-session.md`); the file would vanish with the container.

| Variable | Tool (kb/tools.md) | Guide | Needed for |
|---|---|---|---|
| `URLSCAN_API_KEY` | urlscan.io | `guides/urlscan.md` | source-tech, daily pulls |
| `GCP_SA_KEY` | Google Cloud (BigQuery) | `guides/google-cloud-bigquery.md` | source-tech (HTTP Archive) |
| `MILLIONVERIFIER_API_KEY` | MillionVerifier | `guides/millionverifier.md` | verify (before the first send) |
| `APOLLO_API_KEY` | Apollo | Apollo → Settings → Integrations → API → create key | source-people |
| `MONID_API_KEY` | Monid | monid.ai → dashboard → API keys | find-contact, verify fallback |
| `APIFY_TOKEN` | Apify | Apify console → Settings → API & Integrations → Personal API token | source-social, activity-research |
| `HACKERTARGET_API_KEY` | HackerTarget | after a membership, key in the account page | optional reverse IP |
| `MAILBOX_n`, `MAILBOX_n_PASSWORD` (mode C) | your mailboxes | `guides/mailboxes.md` | `le send`, `le replies` |

Generated by setup, not by the owner (mode A/B): `CRON_SECRET`, `AGENT_TOKEN` (`openssl rand -hex 32`),
`MAILBOX_ENCRYPTION_KEY` (`openssl rand -base64 32`), the Supabase DB password.

After each key: tick it in `kb/setup-state.md` § 5 and fill the row in `kb/sources.md` (on, cap). Caps stay at the
defaults unless the plan or the owner sets a budget (Settings → Caps; mode C: `le ingest '{"caps":{...}}'`).
