# Reply rules

Bundle default (from the author's decision 2026-11-04 and generic practice). Owner rules in `kb/offer.md` win.

| Class | What to do |
|---|---|
| positive (clear yes, "when?") | Answer within minutes in working hours with the booking link and two times. Draft is marked "send now". |
| question | Answer it briefly and offer a call. Draft for the owner to approve. |
| objection | Answer once, briefly, without arguing. Draft for approval. |
| not_now | Thank them, ask when to come back, note the date. Draft for approval. Sequence already stopped. |
| "how did you get my email?" | State the real source (the register, their website, a public post) and offer removal. Draft for approval. |
| unsubscribe | Suppressed automatically everywhere. No answer needed beyond an optional one-line confirmation. Never argue. |
| hostile | Suppress. No answer. Note it for the complaint count. |
| auto_reply | Only recorded; the sequence continues unless it says the person left (then suppress and note). An out-of-office with a return date: pause that person until the date. |
| bounce | Stopped automatically. Count it for stop-loss. |

Answering within 5 minutes vs 30 minutes made leads ~8× more likely to qualify in an old B2B study (sourced, old).
Stop every channel for a person who replied (the app stops email; stop manual LinkedIn too).

v1 does not auto-send replies. Drafts are shown to the owner; the owner sends from the mailbox that received the reply.

Who may handle what (generic practice): an agent may handle out-of-office, bounce, unsubscribe and not-now alone;
positive replies, questions and objections are drafted for a person to send. Log class, date, step and source on the
person so the weekly review can rank sources by positive replies.
